# Implementierungsvertrag V1

Python 3.11+, `jsonschema`, `PyYAML`; keine OpenAI-API, keine Datenbank. Package `medizinanders`; CLI `ma`. Artefakte werden als UTF-8 JSON (gültiges YAML) gespeichert, Vorlage `.json`, Schema JSON Schema 2020-12. Gemeinsam: artefakt_id, projekt_id (MA-YYYYMMDD-NNN), version (SemVer), datum (ISO 8601), autor, status (Entwurf/geprüft/freigegeben/produziert/veröffentlicht), eingaben (Liste {artefakt_id, version, sha256}), quellen (Liste Quellen-IDs), offene_punkte (Liste Text), gesperrt (bool), sperrgrund (Text, leer nur ungesperrt), beispiel (bool), inhalt (Objekt).

Payloads: A01 {kernfrage,nutzen,zielgruppe,scope,ausschluesse,suchfragen,format,ressourcen,offene_entscheidungen}; A02 {suchprotokoll,originalquellen,gegenbelege,unsicherheiten}; Quelle {quelle_id,url,titel,typ,zugriff,geoeffnet_am,fundstellen,lokaler_pfad,sha256,parameter}, zugriff geprüft/nicht_geprueft. A03 {faktenmatrix,claims,risiken,psychologie_map}; Claim {claim_id,aussage,status,einsatz,belege,gegenbelege,einschraenkungen,medizinisch,rechtsrelevant}, Status BESTÄTIGT/TEILWEISE/WIDERLEGT/UNBEWIESEN, Einsatz ja/nur_mit_einschraenkung/nein; Beleg {quelle_id,fundstelle}. A04 {profil,dramaturgie}; A05 {saetze,sprechertext,wortzahl,untertitel_basis,aussprache,overlays,titel,thumbnail,beschreibung,quellenangaben,cta,disclaimer,hashtags}; Satz {satz_id,text,faktisch,claim_ids,funktion}; Publikationsfelder titel/thumbnail/beschreibung/cta als {text,faktisch,claim_ids}. Overlay zusätzlich start/ende. A06 {szenen,assets,invideo_auftrag}; Szene {szene_id,start,ende,sprechertext,funktion,motiv,assetbedarf,sync_anker,overlay,quellenhinweis,uebergang,audio,claim_ids}; Asset {asset_id,typ,beschreibung,rechte_status,rechte_beleg,ki_illustration}, Rechte geklaert/offen. A07 {freeze_revision,manifest_sha256,preflight,qa}; QA {ergebnis,findings,pflichtpruefungen}, Findings {datei,problem,soll,ist,schwere,rueckweg,offen}, ergebnis freigabefaehig/nacharbeit_erforderlich/pruefung_unvollstaendig. A08 {preview_pfad,preview_sha256,produktionsnotizen}; A09 {final_pfad,final_sha256,srt_pfad,srt_sha256,aenderungen}; A10 {datei_sha256,technischer_report,qa}; A11 {final_sha256,video_id,url,sichtbarkeit,veroeffentlicht_am,ki_kennzeichnung,zielgruppe,werbung}; A12 {datenquelle,zeitraum,kennzahlen,beobachtungen,hypothesen,naechster_test}, Kennzahl {wert:null|number,begruendung}, naechster_test genau ein Objekt.

Module: storage.py (atomisch, Sperre, Artefakte, Hashes); validation.py (Schema + Crosscheck); pipeline.py (State/Gates/Freeze/Jobs/Handoffs/Invalidierung); cli.py; workers.py; media.py (separate Zuständigkeit). `media.inspect_video(path: Path, report_dir: Path) -> dict` schreibt JSON Reports, result {ergebnis,findings,pflichtpruefungen,datei_sha256,...}. `media.validate_srt(path, font_path=None) -> dict` gleicher QA-Stil. Messbare fehlende Prüfungen blockieren; menschliche Prüfungen getrennt. ffmpeg nie automatische Korrektur. Eigene Medientests `tests/test_media.py`.

Projekte standardmäßig ~/.local/share/medizinanders/projects; `MA_DATA_DIR` überschreibt Datenspeicher (niemals Git; auch keine Symlinks dorthin). State `state.json`, Artefakte `artifacts/Axx/version.json`, jobs/job-ID/{input,output}, review/, gates/, freeze/rNNN/, handoff/{invideo,youtube}, 08_produktion/inbox/preview.mp4, 09_postproduktion/inbox/final.mp4, 10_qa/, 12_analytics/. Native aktuelle Session: `spawn_agent` mit fork_turns=none. CLI-Worker nur bestätigte `codex exec`-Flags. ma run hält mit WAITING_FOR_CODEX an, wenn kein bestätigter CLI-Modus; native Orchestrator-Anweisung führt isolierte Subagents aus und importiert Output. Keine Approval-Kommandos durch Produktionsagenten. Demo-Modus strikt getrennt; simulierte Gates benötigen --demo-simulate und projekt.beispiel=true. Echte Approval-Befehle nur interaktiv mit Namenseingabe und konkretem Bestätigungstext; kein --yes. G0 wird nie durch Demo real freigegeben.

Reviewergänzungen: A03 enthält den automatisch materialisierten quellenkatalog der referenzierten A02-Originalquellen. Medizinischer/juristischer --stage claims bindet A01–03; --stage production bindet zusätzlich A04–06 und ist bei Relevanz G3-Pflicht. Technische Attestierungen benötigen technical_evidence pro tatsächlichem nicht_geprueft-Punkt; unabhängige K0/K1 sind unverändert Blocker. Freier Import nur A01–06. Jobannahme rollt bei Schreibfehlern zurück. Pushcheck prüft die tatsächliche Git-Historie; Produktionsdaten werden nie öffentlich oder privat ins Pipeline-Git übernommen.

Gate-Rollen: G1 A01; G2 A01–A03 + medizinische/juristische Reviews; G3 A01–A07 + Freeze + Preflight/Red Team; G4 A08 + technische + menschliche Preview-Checks; G5a A09/A10 + Finalhash + technische + menschliche Final-Checks; G5b A11 + tatsächliche private Plattformkontrolle. Freigaben enthalten exakte Hashreferenzen, Identität und Zeitpunkt außerhalb Freeze. Hash-/Konfigänderung invalidiert Freigaben. Draft startet 0.1.0, vor erster Gatevorlage wird 1.0.0-Kandidat erstellt; Approval liegt extern, unveränderliche Dateistatus sind historisch (effektiver Status aus gültigem Gate). Keine automatische Vererbung.

Hauptagent implementiert Core. Schema-Agent: nur schemas/, templates/. Medien-Agent: nur media.py und test_media.py. Rollen/Doku-Agent: nur agents/, docs/ außer diesem Vertrag, config/channel.yaml, config/operator.example.yaml, AGENTS.md. Test/Demo-Agent später separate Zuständigkeit. Alle Änderungen direkt im gemeinsamen Repo, keine eigenen Commits. Sicherheits- und Gateblocker haben Vorrang vor Komfort.
